ПЕРЕКУП ТЕЛЕФОНОВ: как сделать приложение

1. Распакуй архив (в приложении «Файлы» на телефоне).
2. Выложи папку в интернет (бесплатно):
   Вариант А: netlify.com/drop, загрузи архив или файлы папки.
   Вариант Б: GitHub Pages: создай репозиторий, загрузи все файлы (Add file > Upload files), затем Settings > Pages > Deploy from branch > main.
3. Открой полученную ссылку в Chrome, меню (три точки) > «Установить приложение».
4. Для APK: зайди на pwabuilder.com, вставь ссылку, нажми Start > Package for stores > Android. Скачай архив и сохрани файл ключа (он нужен для обновлений).
